# -Ride-Sharing-Analytics-Dashboard About the Project
This project is an interactive Power BI dashboard built to analyze ride-sharing data. The goal was to track revenue, trip status (completed vs. cancelled), and analyze payment method preferences across different cities.

## Tools & Skills Used
* Power BI
* Data Cleaning & Transformation
* Data Visualization
* Dashboard Design (Dark Mode & Neon Yellow Theme)

## Key Metrics Analyzed
* **KPI Cards:** Total Trips, Total Revenue (755K), Average Trip Distance, and Average Rider Age.
* **Funnel Chart:** Visualized the drop-off between Completed and Cancelled trips.
* **Area Chart:** Tracked daily revenue trends over time.
* **Ribbon Chart:** Analyzed which payment methods (Card, Cash, UPI) are most popular in each city.
* **Interactive Slicer:** Added city filters for dynamic data exploration.
